##  Deep Dives & Core Capabilities

###  Scope, Variables & Functions

* `10_let_const.js`
  > Block scoping rules: `let` supports reassignment; `const` locks binding references. `var` avoided.
* `11_arrow_functions.js`
  > Streamlined syntax for concise implicit returns and lexical `this` binding.
* `23_closures_scope.js`
  > Deep dive into lexical scoping: functions retain access to variables from outer enclosing scopes.

---

###  Data Structures & Operators

* `12_destructuring.js`
  > Unpacked array items and object properties into distinct variables using clean, direct assignment.
* `13_spread_rest.js`
  > Combined/cloned dynamic structures with `...spread` and gathered flexible arguments with `...rest`.
* `14_classes_inheritance.js`
  > Implemented Object-Oriented patterns using `class` syntax, constructors, and `extends` keyword inheritance.
* `17_logical_operators.js`
  > Evaluated complex conditions using boolean logic: `&&` (AND), `||` (OR), and `!` (NOT).
* `18_ternary_nullish.js`
  > Streamlined fallback values using ternary expressions `? :`, optional chaining `?.`, and nullish coalescing `??`.
